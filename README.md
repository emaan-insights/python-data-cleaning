# Python Data Cleaning Project

## Project Overview
This project demonstrates data cleaning and preprocessing using Python.

The dataset contains employee information such as employee ID, name, department, age, salary, and joining date.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Data Cleaning Tasks
- Removed duplicate records.
- Handled missing values.
- Standardized department names.
- Converted salary from text to numeric format.
- Converted joining dates into datetime format.

## Final Results
- Removed duplicate employee records.
- Handled missing values.
- Standardized inconsistent data.
- Improved dataset quality for further analysis.

## Project Files
- `data_cleaning.ipynb` – Jupyter Notebook containing the cleaning process.
- `cleaned_employee_data.csv` – Final cleaned dataset.
